# Getting help

- **Questions, ideas and show-and-tell:** [GitHub Discussions](https://github.com/agentforeach/agentforeach/discussions).
- **Bugs:** [open a bug report](https://github.com/agentforeach/agentforeach/issues/new?template=bug_report.yml) with steps to reproduce.
- **Deploying didn't work:** [open a deployment report](https://github.com/agentforeach/agentforeach/issues/new?template=deployment_report.yml). These help us fix the docs as much as the code.
- **Security vulnerabilities:** never in public issues or discussions. Follow [SECURITY.md](SECURITY.md).

Start with the [docs](docs/README.md), especially [Getting started](docs/getting-started.md).
